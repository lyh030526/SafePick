# SafePick 브라우저 확장 프로그램

Chrome·Edge에서 사용자가 열어 둔 **네이버 스마트스토어·브랜드스토어·네이버 쇼핑(window-products) 상품 상세 페이지**의 공개 텍스트를 읽어 로컬 SafePick에 전달하는 Manifest V3 확장 프로그램입니다. 외부 수집 API, 유료 프록시, API 키가 필요하지 않습니다. 스토어에 게시하지 않고 개발자 모드로 무료로 설치할 수 있습니다.

## 설치 및 실행

1. API 서버 `http://localhost:8000`과 Expo 웹 `http://localhost:8081` 또는 `http://localhost:8082`를 실행합니다. [프로젝트 실행 안내](../../README.md)
2. Chrome 주소창에서 `chrome://extensions`를 엽니다. Edge는 `edge://extensions`입니다.
3. **개발자 모드 → 압축해제된 확장 프로그램을 로드**를 누릅니다.
4. 이 폴더(`C:\Users\jsh68\Desktop\SafePick\apps\extension`)를 선택합니다.
5. 네이버 상품 상세 페이지를 직접 엽니다. `https://smartstore.naver.com/스토어/products/상품번호`, `https://brand.naver.com/브랜드/products/상품번호`, `https://shopping.naver.com/window-products/스토어/상품번호` 형식을 지원합니다. 검색 결과·가격비교·카테고리 화면은 지원하지 않습니다.
6. SafePick 확장 아이콘 → **현재 상품 정보 가져오기**를 누릅니다.
7. 제목과 설명을 확인·수정하고 개인정보가 있으면 제거합니다. **실행 중인 SafePick 앱 주소**에서 웹과 같은 주소를 선택합니다(기본 8081, 대체 8082). 확인란을 선택하고 **SafePick에서 확인하기**를 누릅니다.
8. SafePick 화면에서 설명을 재확인하거나 상품 이미지를 추가합니다. AI 전송 동의 후 **분석 시작**을 누릅니다.

분석 결과의 **구매 전 체크리스트**에서 모델/구성품 안내 불일치, 할인·구매 압박 표현, 배송·반품 조건의 원문과 확인 방법을 확인합니다. 상품 상세와 배송·반품 안내를 먼저 펼친 뒤 가져오면 수집 범위를 넓힐 수 있습니다. 확인한 항목은 체크할 수 있으며 현재 화면에서만 유지됩니다.

페이지를 이동하면 이전 탭 접근 권한은 해제됩니다. 변경한 확장 코드가 반영되지 않으면 확장 관리 화면에서 새로고침합니다. 원래 브라우저 프로필에는 자동 설치하지 않습니다.

## 수집 범위와 전달

- 사용자가 버튼을 누른 현재 탭에만 `activeTab`과 `scripting` 권한으로 접근합니다. 상시 실행 콘텐츠 스크립트, 전체 사이트 권한, 쿠키 권한, 백그라운드 크롤러가 없습니다.
- 화면에 표시된 텍스트와 상품 JSON-LD의 상품명·브랜드·모델·가격·판매자 필드만 읽습니다. 계정/장바구니/주문 API를 호출하거나 비공개 내부 상태 전체를 덤프하지 않습니다.
- 폼·입력값·헤더·푸터·숨김 텍스트를 제외합니다. 사이트 마크업에 따라 다른 개인정보가 섞일 가능성이 있어 전송 전 편집 화면을 제공합니다.
- 사업자등록번호가 적힌 '판매자 정보' 블록(상호·대표자·사업자등록번호·통신판매업 신고번호·소재지)은 접혀 있거나 설명이 길어도 잘리지 않도록 따로 읽어 설명 맨 앞에 붙입니다. 네이버 운영사 정보와 페이지 푸터는 제외합니다. SafePick API가 이 번호로 국세청 사업자 상태를 조회합니다.
- 원래 상품 URL과 옵션 쿼리 파라미터를 유지하고, 페이지 제목·최대 12,000자 설명·사용자 기기의 수집 시각을 전달합니다. 수집 시각과 내용의 진위는 인증하지 않습니다.
- 자료는 localhost 앱 URL의 fragment(`#safepick-import=...`)로 전달됩니다. fragment는 HTTP 요청에 포함되지 않고 앱이 읽은 후 즉시 주소창에서 제거합니다. 확장 프로그램 자체는 자료를 저장하지 않습니다. 앱이 열리기 전에는 주소에 내용이 남을 수 있으므로 민감한 자료는 전달하지 마세요.
- 새 앱 탭에서 자동으로 AI를 호출하지 않습니다. 사용자가 자료를 확인하고 분석에 동의한 후에만 기존 SafePick API에 전송합니다.
- 상품 이미지는 확장에서 자동 다운로드하지 않습니다. SafePick 화면에서 사용자가 직접 이미지 파일을 첨부할 수 있습니다.

## 한계

- 접근 차단, 로그인, CAPTCHA, IP 제한을 우회하지 않습니다. 상품 페이지를 정상적으로 열 수 없으면 설명·이미지 직접 제공 경로를 이용합니다.
- 접힌 설명과 이미지 안의 글자는 텍스트 읽기로 가져오지 못합니다. 설명을 펼치거나 필요한 부분의 이미지를 앱에 추가하세요. 12,000자 이후 내용은 제외됩니다.
- 사용자 클릭과 브라우저 권한은 네이버나 판매자의 데이터 이용 허락을 대체하지 않습니다. 공개 배포 시 해당 서비스의 약관과 이용 권한을 별도 확인해야 합니다.
- 현재 로컬 개발 앱(`localhost:8081`/`localhost:8082`) 전용입니다. 앱 주소 선택은 팝업을 열 때마다 기본 8081로 시작하며 별도로 저장하지 않습니다. 모바일 Chrome 확장 설치, 원격 배포, 임의 외부 앱 주소 설정은 제공하지 않습니다.
- 추가 수집 API 요금은 없지만 기존 OpenAI 이미지/텍스트 분석 및 공식 검색 설정에 따른 비용은 별도입니다.

## 검증

새 판매 페이지 → 실제 확장 전송 → 실제 웹/API/모델 → 새 주의 수준 화면의 연속 검증은 `apps/mobile/tests/live-fresh-risk-flow.cjs`로 실행합니다. 이 명령은 실제 네이버 네트워크와 기존 AI/검색 설정을 사용하며 결과는 `docs/validation/2026-10-28/fresh-risk-flow/`에 기록합니다.

앱/확장 통합 테스트: `apps/mobile/tests/material-ui.cjs`. Playwright의 격리된 브라우저 프로필에 확장을 설치하고, 네이버 URL에 **가상 판매 페이지를 응답하는 fixture**로 실제 확장 권한·팝업·자료 전달을 확인합니다. 이 환경에서는 Edge로 검증했습니다. 실제 네이버 운영 페이지의 접근 성공률이나 모든 상세 페이지 마크업을 보장하는 테스트는 아닙니다.

확장 권한: [Chrome activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)

무료 로컬 설치: [Chrome 개발자 문서](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world)
