# 4주차 구현 및 검증

최종 검증일: 2026-10-28 (공식 OpenAI 키 적용 후 재검증)

## 구현 범위

- 공식 도메인 검색 결과 중 최대 3개 페이지를 직접 수집합니다.
- LLM이 공식 상품명, 모델명, 단일 판매 가격, 통화, 구매처 안내와 원문 근거를 추출합니다.
- 원문에 없는 인용문과 값은 제외하고, 모델명이 다르면 동일 상품 판정을 허용하지 않습니다.
- 동일 상품 확인, 유사 상품 확인, 확인되지 않음, 확인 불가 결과를 화면에 표시합니다.
- 동일 상품과 같은 통화의 단일 가격이 확인되면 판매가와 공식 가격의 차이·비율을 계산합니다.
- 공식 링크와 항목별 원문 근거, 판매처 확인 안내를 표시합니다.
- 사용자가 정보를 수정하면 이전 결과를 숨기고 `/comparisons`로 다시 비교합니다.

- Apple AirPods Pro 3의 공식 페이지를 검색·수집하고 `동일 상품 확인` 결과와 공식 구매 안내 원문을 확인했습니다.
- 실제 웹 화면에서 Apple 링크 입력 → 판매 정보 추출 → 공식 검색 → 비교 결과 표시까지 통과했습니다.
- 이번에 수집한 Apple 페이지의 단일 공식 가격 근거는 부족해 가격은 `확인 불가`, 가격 차이는 계산 불가로 표시했습니다.
- 다른 브랜드 전체와 모든 쇼핑몰의 성공을 의미하지 않습니다. 사이트 접근 제한과 공개된 정보에 따라 결과가 달라집니다.

### 실제 공식 페이지에 대한 변경 입력 대조군

- AirPods Pro 2를 AirPods Pro 3 공식 페이지와 비교: 유사 상품, 가격 계산 제외.
- AirPods Pro 3 호환 실리콘 케이스를 본체 공식 페이지와 비교: 유사 상품, 가격 계산 제외.
- 수동 입력 판매가 299,000 KRW와 실시간 공식가 369,000 KRW 비교: -70,000 KRW, -18.97%.

299,000 KRW는 재비교 기능 검증을 위한 임의 입력이며 실제 판매처에서 관측한 가격이 아닙니다. 공식 가격과 근거 문장은 실제 Apple 페이지에서 추출했습니다. 차단 때문에 근거를 읽지 못한 대조군은 성공으로 집계하지 않습니다.

### 검증 중 반영한 보완

- LG 실제 HTML이 약 1.2MB여서 차단되던 문제를 해결하도록 수집 상한을 1MB에서 2MB로 조정했습니다. 스트리밍 크기 제한과 URL 보안 검사는 유지합니다.
- 공식 검색은 Apple 한국 페이지와 삼성 한국 페이지 등 국내 공식 사이트를 우선 대상으로 합니다.
- 입력 링크 자체가 공식 도메인이면 해당 페이지도 최대 3개 비교 근거 후보에 우선 포함합니다.
- 사용자 모델 코드의 근거가 없으면 상품명만 같다는 이유로 동일 상품이라고 판정하지 않습니다.
- AI 서비스 오류와 페이지 수집 오류를 구분하고, 내부 오류 본문이나 키 값은 표시하지 않습니다.

## 재실행

API 폴더에서:

```cmd
python -m unittest discover -s tests -v
```

서버가 실행 중일 때 실제 API 연동 검사:

```cmd
python tests/live_comparison.py
```

모바일 폴더에서:

```cmd
npm run lint
npx tsc --noEmit
```

`apps/mobile/tests/week4-ui.cjs`는 Playwright와 Microsoft Edge, localhost:8081 웹 서버가 필요합니다. 기본 실행은 외부 API 응답을 고정 데이터로 대체합니다. `PLAYWRIGHT_MODULE`에는 별도로 설치한 Playwright 모듈 경로를 지정할 수 있습니다. `LIVE_UI=1`을 설정하면 실제 Apple 링크 분석도 추가로 실행하며 AI·검색 API를 호출합니다.

실제 상품 묶음 재검증은 API 폴더에서 다음과 같이 실행합니다. 실제 AI·검색 API를 호출하며 공개 상품 응답과 원문만 저장합니다.

```cmd
python tests/validate_real_products.py --controls --output ../../docs/validation/latest/live-results.json
python tests/validate_real_products.py --cases none --price-control --output ../../docs/validation/latest/price-control.json
```
