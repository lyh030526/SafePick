# 실제 네이버 쇼핑 상품 페이지 검증

검증일: 2026-10-28 (한국 시간)

대상: https://shopping.naver.com/window-products/kurlynmart/13807617262

기존 확장과 앱의 URL 검증은 스마트스토어·브랜드스토어 형식만 허용했습니다. 네이버 쇼핑의 `/window-products/{store}/{productId}` 형식을 양쪽에 추가하고 확장 버전을 0.1.1로 올렸습니다.

## 실제 서비스 요청 결과

- 격리된 Edge 테스트 프로필에서 **실제 네이버 URL**을 열었으며 가상 응답·프록시·로그인·CAPTCHA 우회를 사용하지 않았습니다.
- HTTP 200. 페이지 제목: `컬리N마트 : 네이버+ 스토어 : 상품상세 : [농심] 너구링 100g`.
- 실제 설치한 확장 프로그램에 action으로 activeTab 권한을 부여한 뒤, 설치된 popup 문서를 테스트 탭으로 열어 `chrome.scripting`으로 현재 페이지를 읽었습니다.
- 수집된 설명은 4,001자이며, 상품명·표시 가격·판매처를 포함했습니다. 수집한 URL은 입력 주소와 동일합니다.
- 이 설명을 로컬 SafePick `/analyses`에 제공 자료로 전달하여 기존 OpenAI 설정으로 실제 추출했습니다. 상품 페이지를 재수집하지 않는 경로입니다.

## 재현

모바일 폴더에서 `node tests/live-naver-extension.cjs`를 명시적으로 실행합니다. Playwright 설치 경로를 별도로 사용할 경우 `PLAYWRIGHT_MODULE`을 설정합니다. 이 스크립트는 실제 URL 한 개와 확장 수집을 검증하며 AI를 호출하지 않습니다. AI 응답은 별도 실제 API 호출로 기록했습니다.

확장 → 앱 전달 회귀 테스트는 `TEST_PRODUCT_URL`에 위 URL을 설정하고 `tests/material-ui.cjs`를 실행했습니다. 이 회귀 테스트의 상품 응답은 가상 fixture이고, 위 실제 요청 결과와 구분합니다.

현재 URL에서 성공했으며, 다른 네이버 상품 페이지의 마크업이나 접근 조건까지 보장하는 결과는 아닙니다. 기존 확장을 설치한 경우 확장 관리 화면에서 새로고침한 뒤 사용합니다.
