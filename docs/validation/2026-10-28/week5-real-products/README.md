# 5주차 실제 판매 페이지 추가 검증

검증일: 2026-10-28 (한국 시간)

이번 검증은 이전 텍스트를 재사용한 평가와 별개로, **실제 판매 페이지 12개를 새로 열어** 진행했습니다. 판매 중인 상품 10개는 실제 SafePick 확장으로 수집하고 실행 중인 `POST /analyses`에 전송하여 기존 설정의 OpenAI와 공식 검색을 호출했습니다. 판매 중지 상품 1개와 운영 중지 스토어 1개는 수집 단계에서 안내하고 분석 대상에서 제외했습니다.

## 방법과 확인 범위

- 격리된 Edge 프로필에 실제 확장을 설치하고, 상품 탭에서 확장 액션으로 `activeTab`을 부여한 뒤 수집 버튼을 실행했습니다. 사용자 평소 브라우저 프로필은 변경하지 않았습니다.
- 공개 페이지를 정상적으로 열어 읽었습니다. 로그인, 프록시, 접근 제한 우회, 별도 유료 수집 API, 네이버 응답 대체용 fixture는 사용하지 않았습니다.
- 상품 주소와 상품명이 일치하는지, 수집 주소가 API 결과에도 보존되는지, 상품명·브랜드·표시 가격이 실제 자료에 있는지 대조했습니다.
- 위험 항목뿐 아니라 **모든 조건 인용문**이 수집 원문에 포함되는지 검사했습니다. DOM 줄바꿈/공백을 보정하더라도 화면에는 실제 원문 구간을 반환합니다.
- 배송·반품 안내가 실제 수집 자료에 있는 경우 추출되는지도 확인했습니다. ‘신호 없음’이나 인용 검증 통과를 정품/안전/판매자 신뢰도 판정으로 해석하지 않습니다.
- 화면 회귀는 별도의 fixture 테스트입니다. 실제 상품 10개의 API 검증과 구분합니다. 기존 8081 포트는 다른 서버가 사용 중이어서 그대로 두고 웹은 8082에서 실행했습니다. UI 테스트는 확장이 원래 8081 주소를 생성하는 것을 확인한 뒤 전달된 fragment를 8082 웹으로 옮겨 검사했습니다.

## 발견한 문제와 보정

1. AI가 인용문을 JSON 문자열로 한 번 더 인코딩하면 원문에 있는 배송·반품 안내가 탈락했습니다. 한 번만 디코딩한 후보를 **다시 실제 원문과 대조**하도록 보정했습니다. 인용 자료를 일반 텍스트로 전달하고 추가 따옴표를 넣지 않도록 지침도 바꿨습니다.
2. `배송비 / 3,000 / 원`처럼 여러 DOM 텍스트 노드로 나뉜 금액을 `3,000원`으로 응답하면 인용이 탈락했습니다. 공백만 다른 경우 원문의 해당 구간을 찾아 원래 형태로 반환합니다. 금액·문자·문장부호가 다른 인용은 계속 제외합니다.
3. 판매 중지/스토어 운영 중지 화면이 설명으로 수집되었습니다. 짧은 중지 안내 화면을 차단하고 팝업에 원인을 표시하도록 수정했습니다. 실제 두 주소에서 수집 미리보기가 열리지 않는 것을 재확인했습니다.
4. 식품 패키지 표기 변경을 구성품 누락 대상으로 삼거나, `판매단위`, `중량/용량`, `옵션 선택 (필수)` 제목만으로 구체적 정보가 있다고 처리했습니다. 필요한 구성품 확인 대상과 메뉴 필터를 보강했습니다.
5. 서로 다른 맛 옵션의 구성품이 합쳐지거나 상품번호가 모델명으로 응답된 사례가 있었습니다. 상품번호/SKU와 제조사 모델명을 구분하고, 미선택 옵션들을 하나의 구성으로 합치지 않도록 추출 지침을 보강했습니다. AI 추출 전체에 대한 정확도 보장은 아닙니다.
6. `무료교환반품`만 인용하면서 바로 뒤의 `(최초 1회 무료, 도서산간 지역 별도)`가 빠진 사례가 있었습니다. 이처럼 직접 붙은 제한 조건을 실제 원문에서 함께 보존하도록 보정했습니다.

## 검증 결과와 남은 한계

- 실제 12개 페이지 중 판매 중인 **10개를 수집·실제 API 분석 완료**, 중지 화면 2개 안내.
- 10개 모두 HTTP 200, 원래 상품 URL 보존, 조건/체크리스트의 모든 인용문 원문 검증 통과.
- 배송 안내 10개, 반품·교환 관련 안내 8개 확인. 나머지 반품 안내 2개는 수집 범위 부족으로 추가 확인 안내.
- 원문에 관측한 구체적 배송/반품 표현의 추출 확인 10개 통과. 이것은 모든 조건을 빠짐없이 추출했다는 지표가 아닙니다.
- Python 단위/API 테스트 59개 통과, TypeScript·ESLint 통과.
- 실제 확장 액션/권한·동의·앱 전달·이미지 첨부·390px/1440px UI 회귀 통과(가상 상품/API 응답을 사용하는 별도 테스트).
- 기존 실제 AI 대조 평가 6개도 인용 처리 보정 후 재검증 통과: 합성 정상/불일치/할인/압박 5개 + 이전 실제 네이버 수집 1개.


- 선택한 옵션이 없는 상품의 가격은 **페이지 표시 가격/최저가 범위**입니다. 결제 금액이나 모든 옵션의 구성품을 확정한 결과가 아닙니다. 짬뽕 상품은 `13,770원~`로 응답되어 옵션 선택과 보정 입력이 필요합니다.
- 소니 판매 페이지 자체는 읽혔지만, 비교 대상인 소니 공식 사이트 수집은 403으로 막혀 `unknown`입니다. 삼성 메모리카드는 공식 검색 `no_results`이며 동일 제품 비교를 확정하지 못했습니다. 공식 사이트 결과 부족 자체를 위험 신호로 삼지 않습니다.
- 너구링·소니는 최종 수집 자료에 구체적인 반품 안내가 없어 `확인 필요`로 남았습니다. 너구링은 앞선 더 긴 수집에서는 반품 안내가 포함됐지만, 이번 재수집에서는 상세 내용이 덜 읽혔습니다. 로딩 시점·접힌 안내·이미지 중심 상세 설명에 따라 수집 범위가 달라질 수 있습니다.
- 떡볶이의 반품·교환 `found`는 **떡 갈라짐 시 교환** 문구를 확인했다는 뜻입니다. 일반적인 변심 반품 기한/비용 전체를 확인했다는 뜻이 아닙니다. `found`는 일부 관련 원문이 있다는 상태이며 조건의 완전성을 보장하지 않습니다.
- 최종 10개 자료에서 추가 위험 표현이 탐지되지 않았습니다. 실제 악성 판매 페이지를 정답 라벨로 구축한 평가가 아니므로 위험 신호 재현율이나 전체 오탐률을 산출하지 않습니다. 식품 비중이 높고 테무·알리·쿠팡은 이번 검증에 포함하지 않았습니다.
- 8081 포트가 현재 다른 서버이므로 사용자가 확장에서 앱으로 바로 이동하려면 웹을 원래 8081에 실행하거나 앱 접속 주소 설정을 별도로 맞춰야 합니다. 이번 작업에서 기존 8081 프로세스는 종료하지 않았습니다.
